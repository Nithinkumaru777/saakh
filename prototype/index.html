How a decision is made

  1. 1

    Policy rules

    Six hard limits, such as EMIs above 65% of income, decline straight away.

  2. 2

    Features

    Income, debts and the loan become ratios lenders use: FOIR, loan-to-income, loan-to-value.

  3. 3

    Risk model

    A gradient-boosted model estimates the probability of default within a year.

  4. 4

    Explanation

    SHAP values show how much each input raised or lowered that risk.

  5. 5

    Decision

    Grade A to E sets the outcome, the indicative rate and the maximum amount.

How the AI decides

Policy rules screen the application, a gradient-boosted model estimates default risk, and SHAP values explain each prediction.

Which inputs matter most

Average absolute effect on default risk across the synthetic sample (mean |SHAP|, percentage points)

Intended use

Helps a loan officer screen retail loan applications and explains the result to the applicant. It supports the decision; a person makes the final call on referred cases.

Model

XGBoost classifier with monotone constraints (a higher CIBIL score can never raise risk; higher EMIs, utilisation, missed payments and enquiries can never lower it), calibrated with Platt scaling. Logistic regression is kept as a baseline.

Data

5,000 synthetic applicants modelled on Indian retail lending ranges, generated with a fixed seed so results are reproducible. Split 70/15/15 for training, calibration and testing.

Inputs

CIBIL score, credit history, utilisation, missed payments, enquiries, past default, EMI-to-income ratio, loan-to-income, loan-to-value, debt-to-income, employment, tenure, dependents, residence, city tier and loan type.

Explanations

SHAP TreeExplainer gives each input's contribution to a single prediction. Contributions are converted to percentage points of default risk and written as plain sentences.

Not used

Gender, religion, caste and other protected attributes are never collected or used.

Limitations

Trained on synthetic data, so absolute risk levels are illustrative. Before real use it must be retrained and validated on actual repayment history.
